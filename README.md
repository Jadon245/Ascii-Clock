ASCII Clock Generator
A Python program I created for Texas A&M Engineering 102.

Enter the time: 12:60
The entered value was formatted incorrectly, please enter a correct time: 12:59
Choose the clock type (12 or 24): 12
Enter your preferred character: #
The time is:

 #  ###   ### ### PPP M   M
##    # : #   # # P P MM MM
 #  ###   ### ### PPP M M M
 #  #   :   #   # P   M   M
### ###   ### ### P   M   M

Features:

Validates military time input
Converts between 24-hour and 12-hour formats
Generates ASCII-art representations of times
Supports custom drawing characters
Concepts Used:

Dictionaries
Nested Lists
Loops
Input Validation
String Manipulation
